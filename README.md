# uscal ✳

각자의 하루 사이, 우리가 만날 수 있는 시간. 모바일과 PC에서 사용하는 모임 일정 조율 웹 프로토타입입니다.

## 실행

Node.js 22.12 이상(현재 검증: 24.19), npm을 사용합니다.

```sh
npm ci
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

## 첫 버전에서 체험하기

1. 로그인 화면에서 ‘데모 계정으로 둘러보기’를 선택합니다. 카카오·구글은 실제 인증 미연결 상태로 비활성화되어 있습니다.
2. 친구 메뉴에서 수연의 샘플 요청을 수락하거나 민준#1024를 검색해 요청을 보냅니다. 발신 요청은 실제 상대에게 전송되지 않습니다.
3. 모임 만들기에서 친구를 선택합니다. 하늘#0317처럼 친구가 아닌 샘플 사용자도 검색해 선택할 수 있습니다.
4. 모임에서 날짜를 고르고 사람별 일정과 공통 빈 시간(09–22시, 1시간 단위)을 봅니다. 다른 사람의 일정은 제목 없이 ‘일정 있음’으로 표시됩니다.
5. 모임 채팅에서 날짜를 이야기하고 공통 시간 버튼 또는 확정 버튼으로 약속을 만듭니다.
6. 달력/모임의 확정 약속을 열고 댓글을 남깁니다.

공동 일정은 참여자 ID를 가진 하나의 이벤트로 관리됩니다. 확정된 약속도 이후 빈 시간 계산에서 제외합니다. 겹치는 공동 일정은 확정할 수 없습니다. 개인 일정은 겹쳐서 입력할 수 있습니다.

## 현재 범위

- 샘플 친구와 단일 사용자로 체험하는 UI 프로토타입입니다.
- 데이터는 현재 브라우저의 localStorage(`uscal-v1`)에만 저장됩니다.
- 실제 로그인, 초대 링크, 다른 기기/사용자 간 동기화, 알림, 외부 캘린더 연동은 아직 없습니다.
- 개인정보 접근 통제는 백엔드 구현 단계에서 필요합니다. 현재 UI의 개인 일정 비공개 문구는 목표 동작을 설명하며 실제 다중 사용자 보안 기능은 아닙니다.
- 후보 투표, 실제 사용자 간 실시간 메시지 전달, 일정 수정은 후속 범위입니다. 현재는 생성·삭제·댓글을 지원합니다.
- 데모를 초기화하려면 브라우저 개발자 도구에서 위 localStorage 키를 삭제합니다.

## 검증

공통 빈 시간 계산 및 날짜 변환 테스트, 프로덕션 빌드, Chromium을 통한 약속 확정·댓글·새로고침 후 보존·모바일 가로 넘침 검사를 수행했습니다. 브라우저 자동화 도구는 저장소 의존성에 포함하지 않았습니다.

## 다음 단계: 실제 계정과 공유

현재 친구 요청/채팅/모임은 모두 로컬 데모이며, UI 흐름을 검토하기 위한 구현입니다. 생년월일 대신 이름#고유번호를 검색 ID로 사용합니다. 데모 로그인 플래그는 인증이나 보안 경계가 아닙니다.

실제 소셜 로그인을 연결하려면 카카오 Developers·Google Cloud에서 서비스 앱/OAuth 클라이언트를 등록하고, 공개 사이트의 리디렉션 URL을 지정해야 합니다. 서버/DB 호스팅도 선택해야 합니다. 비밀 키를 GitHub Pages나 Vite 환경 변수에 넣으면 안 됩니다. 서버에서 인증 세션과 친구 요청 상태, 모임 가입 동의, 멤버 권한을 검증하고, 다른 사용자의 개인 일정은 제목/장소/메모를 제거한 busy 구간만 API로 반환해야 합니다. 실시간 채팅/동기화는 해당 서버를 통해 구현해야 합니다.
